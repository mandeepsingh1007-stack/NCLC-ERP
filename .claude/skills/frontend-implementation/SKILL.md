name: frontend-implementation
description: Implement metadata-driven React/TypeScript UI components and flows.
---

Use reusable primitives rather than business-specific field definitions.
Use React Hook Form for forms and TanStack Query for server state.
Every screen must define loading, empty, error, success and permission-denied states.
Use accessible labels, keyboard navigation, focus management and responsive layout.
Do not duplicate backend business rules as the security boundary.
Add component/E2E tests for critical flows.
